## Core ROC Competencies

### 1. Fleet Uptime & Real-Time Monitoring

ROC teams use industrial SCADA/HMI systems to track:
- **Power output** (MW/MWh real-time)
- **Thermal signatures** (cell temperatures, cooling system efficiency)
- **Electrical health** (voltage/current, harmonic distortion, inverter frequency sync)
- **Grid synchronization** (phase lock, voltage phase angle)
- **Event logging** (trip codes, maintenance flags, firmware alerts)

**Industry Standard Tools:**
- HybridOS (Powin/FlexGen standard)
- ABB/Schneider SCADA interfaces
- Victron/Fronius monitoring protocols
- Custom Python/Java event aggregators

**Salary Impact:** Mastery of **2+ major SCADA platforms** = +$8K–$15K annually.

### 2. Predictive Maintenance & Failure Prevention

ROC Operators develop intuition for failure patterns:

**Thermal Signatures:**
- Rising baseline cell temperature (even at partial SoC) = cell degradation starting
- Temperature spread across pack (>5°C delta) = cooling system wear
- Sudden temperature spike on discharge = imminent thermal runaway risk

**Electrical Signatures:**
- Voltage creep on same discharge cycle = cell impedance rising (age marker)
- Harmonic distortion increasing = inverter component degradation
- Soft startup current spikes = firmware/firmware/control loop friction

**Predictive Actions:**
- Flag for firmware update (often corrects control loop issues)
- Recommend SoC de-rating (reduces stress on aging cells)
- Schedule site inspection (find cooling fan wear, electrolyte leaks early)
- Propose capacity test (under NDA, validate remaining warranty life)

**Real Value:** Finding 1 failure before it catastrophically fails = **$200K–$1M saved** (penalties + replacement costs + logistics).

### 3. Event Analysis & Root Cause Determination

When a system trips, ROC teams answer: **Was this the battery's fault, the grid's fault, or the inverter's fault?**

**Typical Analysis:**
1. Pull SCADA logs (millisecond-level data from last 5 minutes)
2. Check grid operator data (did voltage drop? frequency spike?)
3. Review firmware version and recent updates
4. Compare against "signature database" of known failure modes
5. Collaborate with OEM if needed (Powin, LG, BYD, etc.)
6. Generate report for PPA compliance team

**Business Impact:**
- **Grid Fault?** → Not your liability, file claim, prove via data
- **Battery Fault?** → Warranty claim coordination, expedite replacement, minimize downtime
- **Inverter Fault?** → Coordinate with inverter OEM, often under separate warranty
- **Control System Bug?** → Deploy firmware patch, prevent recurrence across fleet

**Real Case:** A 50 MW system in California tripped during peak export. Without proper event analysis, the developer would eat $75K/day in PPA penalties. ROC team proved via SCADA that grid voltage sag caused the trip (grid operator's fault). Developer recovered $225K in penalty credits.

### 4. 24/7 Availability & Crisis Management

ROC teams operate **24/7 shifts** covering all time zones where fleets operate.

**Shift Structure:**
- Team of 4–6 operators covering 3 shifts (8 hrs each)
- Senior/Lead on nights + weekends (supervises remote troubleshooting)
- Pager on-call rotation during planned maintenance windows

**Crisis Scenarios ROC Must Handle:**
- **Thermal runaway beginning:** Execute controlled shutdown, notify site personnel, coordinate emergency response
- **Grid disturbance:** Confirm system survived, monitor for instability, report to grid operator
- **Firmware bug:** Deploy patch across fleet in coordinated manner, monitor for side effects
- **Customer notification:** Explain downtime, provide clear ETA for recovery

**Compensation Model:**
- Base: $125K–$145K
- **Night shift premium:** $8K–$12K/year
- **On-call rotation:** $3K–$8K/year
- **Portfolio bonuses:** $10K–$30K if fleet hits uptime targets
- **Performance bonus:** $15K–$50K if zero critical failures in year
